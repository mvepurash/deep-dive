# Глубокое погружение

Игра для платформы Яндекс Игры.

## Статус

Проект на старте. Структура и наработки появятся здесь по мере разработки.

## Что можно перенести из «Тайны Астероида»

В соседнем проекте уже отлажено и переносится почти без изменений:

- **Локализация** — автоопределение языка через SDK площадки (требование п. 2.14),
  ручное переключение с запоминанием выбора, отдельные наборы картинок на язык
  с автооткатом на русский
- **Интеграция SDK** — подключение, сигнал готовности площадке, показ рекламы
  с кулдауном, работа в запасном режиме вне Яндекса
- **Сборка дистрибутива** — скрипт, который собирает ZIP правильной структуры
  и сам проверяет, что не остались отладочные настройки
- **PWA** — установка игры на домашний экран телефона
- **Механика калибровки кнопок** — зоны нажатия с точным замером по макету,
  эффект нажатия, поддержка разных координат для разных языков
