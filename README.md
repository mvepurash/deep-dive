# Глубокое погружение

Игра для платформы Яндекс Игры. Вертикальный экран, 480 × 854 (9:16).

Батискаф падает в глубоководное ущелье. Стены сужаются, на них растут
существа, снизу поднимается живность. Цель — уйти как можно глубже.

## Структура

```
index.html            точка входа
js/                   модули игры
assets/
  ui_designs/         экраны интерфейса
  sprites/            дрон, существа, элементы HUD
  sfx/  music/        звук
docs/                 ТЗ, референсы, прототип
_unused/              архив неиспользуемого
```

## Документы

- `docs/artist_brief_ru.md` — ТЗ художнику на экраны
- `docs/ref_creatures_*.png` — листы существ (17 видов)
- `docs/ref_title_draft.png`, `ref_briefing_draft.png` — черновики экранов
- `docs/prototype_v1.html` — ранний прототип механики (450×850)

## Статус

В разработке. Механика не зафиксирована, идёт проектирование.
