# English screens

Same file names as the parent folder. The folder selects the language,
not the name.

Required: `title_screen`, `howto_screen`, `pause_screen`,
`settings_screen`, `game_over_screen` — all `.webp`.

Geometry must match the Russian version pixel for pixel. The simplest
way: open the Russian file and replace only the text.

A missing file here is not an error — the game silently falls back to
the Russian one.
