# Заставки

Схема та же, что в «Тайне Астероида» — проверена на публикации.

```
assets/ui_designs/          русский (язык по умолчанию)
assets/ui_designs/en/       английский, имена файлов ТЕ ЖЕ
assets/icons/               значки без текста, одни на все языки
```

**Имена файлов в обеих папках совпадают.** Язык выбирает папка, а не имя.
Если английского файла нет — программа молча возьмёт русский, игра не
сломается.

## Пять экранов

| Файл | Экран | Русский | Английский |
|---|---|---|---|
| `title_screen` | Главный | есть | нет |
| `howto_screen` | Как играть | нет | нет |
| `pause_screen` | Пауза | нет | нет |
| `settings_screen` | Настройки | нет | нет |
| `game_over_screen` | Конец погружения | нет | нет |

## Формат

- В репозиторий кладутся **`.webp`**, конвертирую я
- Художник присылает **`.png`**, полный размер
- Холст **480 × 854** или кратно больше, пропорция 9:16 строго
- `title_screen` и `howto_screen` — фон залит
- `pause_screen`, `settings_screen`, `game_over_screen` — **только окно
  на прозрачном фоне**, на том же холсте 480 × 854

**Геометрия русской и английской версии должна совпадать пиксель в
пиксель.** Проще всего: взять русский файл подложкой и заменить только
текст. Иначе кнопки при смене языка поедут, и подсветку нажатия придётся
подгонять под каждый язык отдельно.

Полное ТЗ на каждый экран — `docs/tz_screens_ru.md`.
