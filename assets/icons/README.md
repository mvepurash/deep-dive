# Значки

Без текста, одни на все языки — в папки ru/en не раскладываются.

| Файл | Что | Размер |
|---|---|---|
| `icon_sound_on` | звук включён | 96 × 96, прозрачность |
| `icon_sound_off` | звук выключен | 96 × 96, прозрачность |

Рисунок должен стоять **в одинаковом положении в обоих файлах** — иначе
при переключении значок заметно прыгает.
